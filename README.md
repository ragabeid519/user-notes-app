# 📝 Flutter Notes App

A modern and user-friendly **Notes Application** built with **Flutter** and **SQLite**, focusing on clean architecture, smooth UI, and real-world features like location tracking and offline storage.

---

## 🚀 Features

- ✏️ Add, edit, and delete notes  
- 🔍 Search notes by title or description  
- ✅ Mark notes as **Completed / Pending**  
- 📍 Save the user’s **current location** when creating or editing a note  
- 🗺️ Open saved location directly on the map  
- 💾 Offline local storage using **SQLite (Floor ORM)**  
- 🔄 Safe database operations using **Transactions**  
- 📳 Shake the device to delete all notes (with confirmation)  
- 🎨 Modern UI using **Material 3**  
- ⚡ Smooth navigation and state management
